# ПУЛЬС · правила работы в интегрированной ветке

Актуальная постановка v2 приведена в CONCEPT.md и ARCHITECTURE.md. Для продолжения работы сначала прочитайте TASKS.md и README.md. Изменения математики, смысла факторов и правил обработки персональных данных требуют согласования с владельцем.

ML владеет расчётами, правилами, весами, цветами, сопоставлением перспектив и подбором мероприятий. Backend отвечает за реестр, приём, версии и хранение. UI отображает расчёты ML. Проверяйте связность исходных цитат, сумму вкладов, общий знаменатель при агрегации и идемпотентность событий.

Реальные анкеты и таблицы обрабатывайте локально. Данные, локальные веса модели, БД и скриншоты с ответами храните в игнорируемом каталоге data/. Публичные примеры API формируйте на отдельном синтетическом наборе. Внешняя обработка предоставленных анкет требует отдельного разрешения. Предварительные экспертные правила утверждает человек.

Сохраняйте работоспособность API v1, старых тестов и страницы /legacy. Правила в ml_service/AGENTS.md описывают первоначальную ML-систему и общие требования к доказательствам. Текущее двухкомпонентное поведение определяется корневой спецификацией.
